🔗 把「开学啦」变成一条链接（免费发布教程）
============================================

你的文件：开学啦网页版/index.html（一个文件，就是整个小程序）
发布后，你会得到一个网址，把这个网址发给朋友，点开就能玩！

----------------------------------------
方法一：Vercel（最推荐，最简单，约 5 分钟）
  1. 电脑浏览器打开 https://vercel.com ，点 Sign Up 注册
     （可以用 GitHub 账号，也可以直接用邮箱注册）
  2. 登录后点 "Add New..." -> "Project"
  3. 选 "Deploy without Git"（不连 Git 仓库）
  4. 把你电脑上的「开学啦网页版」文件夹整个拖进上传框
  5. 点 Deploy，等十几秒
  6. 完成！得到一个网址，比如 https://kaixuela-xxxx.vercel.app
  7. 复制这个网址发给朋友，点开就能玩！

----------------------------------------
方法二：GitHub Pages（免费，电脑上操作）
  1. 注册 GitHub：https://github.com （免费）
  2. 新建仓库（New repository），名字随意，选 Public（公开）
  3. 上传「开学啦网页版」文件夹里的 index.html
  4. 进仓库 Settings -> Pages -> Source 选 main 分支 -> Save
  5. 等 1~2 分钟，网址是 https://你的用户名.github.io/仓库名/
  6. 打开网址就是你的「开学啦」！

----------------------------------------
方法三：Netlify（拖拽上传，和 Vercel 类似）
  1. 打开 https://app.netlify.com/drop
  2. 把「开学啦网页版」文件夹拖进去
  3. 几秒后得到 https://xxxx.netlify.app 链接

----------------------------------------
小提示
  - 在微信里打开链接，个别时候会提示"继续访问"，点"继续"就行
  - 想复制链接：打开你的网址，点网页上的「复制链接分享」按钮
  - 链接打不开时，先用手机浏览器（不是微信）打开试试
  - 这些平台免费额度足够个人使用，不需要花钱
